# Пробная подписка Happ для домашнего интернета

Пользователи один раз добавляют HTTPS-ссылку GitHub Pages. GitHub Actions раз в два часа читает четыре выбранных публичных источника, проверяет HTTPS через узлы и обновляет файл Happ. В подписку попадает до 20 проверенных узлов с указанием страны выхода.

- [x] Проверить разбор plain text и Base64, устранение дублей и экспорт Happ на небольших тестовых данных.
- [x] Прогнать сборщик с актуальными данными четырёх источников и ядром Mihomo. Проверить страну по выходному IP и сохранение опубликованной подборки при пустом результате.
- [x] Опубликовать пробную подписку через GitHub Pages, запустить workflow вручную и сверить 20 узлов по публичному URL.

Источники включают обычные списки igareck и wlunlocker, подборку best от morpheusadam и Sub1 от barry-far. Замеры GitHub Actions отражают сеть раннера. Доступность из домашнего Wi‑Fi проверяется клиентом.
